# Независимая проверка рамок

Проект [Review 11957](https://tasks.yandex.ru/requester/project/11957) принимает снимок и набор нормированных рамок. Ревьюер видит кадр целиком, может скрыть рамки и выбирает один из пяти ответов. Интерфейс на Конструкторе шаблонов выдаёт несколько фото на одной странице, клавиши 1–5 выбирают вердикт на активной карточке.

- [Инструкция исполнителю](instructions.html) и [шаблон](interface.template-builder.json).
- [Обучение](../tasks_train.tsv), [экзамен](../tasks_exam.tsv) и [рабочие контроли](../tasks_honeypots.tsv).
- [Фактические настройки, ID и затраты по всем этапам](../../../results/review/pools_public.json).

После обучения к экзамену допускаются исполнители с 80% правильных вердиктов. Экзамен содержит 8 кадров, для допуска к ревью нужно 6 верных ответов. Навык для ревью — `21829`. Рабочие пулы содержат по одному контролю на страницу. После минимум пяти ответов на контроли результат ниже 75% ограничивает доступ к рабочему пулу. В основных раундах на фото приходится два ревьюера. На дополнительных раундах используется один новый голос. Автор рамок исключается из ревью на уровне страниц.

`collect.py` выгружает первый раунд. `score_bbox_exam.py` считает метрики дополнительного экзамена на разметку рамок, а режим выдачи навыка применяет отдельно сохранённые результаты ручной проверки. `followup.py` содержит настройки дополнительных платных пулов и операции запуска.

Для обновления опубликованной выгрузки запустите `python3 yandex_tasks/review/setup/export_delivery.py` из корня репозитория с токеном командного аккаунта в переменной `TEAM30_TASKS_TOKEN`. Скрипт читает ответы Яндекс Заданий и обновляет локальные JSONL. Датасет, происхождение ответов, журнал исправлений и результаты этапов перечислены в [README проекта](../../../README.md).
