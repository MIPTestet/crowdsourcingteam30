# Первичная разметка бабочек

Дата выгрузки: 17.11.2026. Проект Яндекс Заданий: `11838`, основной пул: `6867722`.

Размечались все взрослые дневные и ночные бабочки. Каждому объекту соответствует отдельная прямоугольная рамка.

## Состав данных

| Файл | Содержание |
|---|---|
| `annotations_400.jsonl` | 400 записей: ответы, рамки, комментарии, признаки для проверки и происхождение ответа. |
| `review_candidates.tsv` | 399 ответов для загрузки во второй этап разметки. |
| `needs_annotation.json` | Одно фото без разметки из-за ошибки загрузки. |
| `quality_report.json` | Результаты экзаменов, контрольных заданий и проверка покрытия датасета. |

Старые ответы неудачного пилота заменены ответами основного пула.

## Формат ответа

В JSONL одна строка соответствует одной фотографии. Основные поля:

- `photo_id`, `image_url` — идентификатор и ссылка на фото;
- `status` — `has_butterflies`, `no_butterflies` или `load_error`;
- `boxes` — список рамок с полями `shape`, `left`, `top`, `width`, `height`;
- `source` — автор ответа, идентификаторы пула, страницы, задания и ответа, время отправки UTC;
- `review_flags` — признаки для приоритетной проверки;
- `unavailable_for_review` — автор, которого нужно исключить из проверки этого ответа.

Координаты рамок нормированы относительно размеров изображения. Начало координат — левый верхний угол. Для изображения размером `W × H`: `x = left × W`, `y = top × H`, `w = width × W`, `h = height × H`.

Фото `449740665` имеет `status=load_error` и `requires_annotation=true`. Пустой список рамок в этой записи не означает отсутствие бабочек. Фото необходимо доразметить.

## Проверка качества

Выполнено 100 страниц: по четыре рабочих и одному контрольному фото. Перекрытие — 1. Получены 399 ответов корректного формата; дубликатов рабочих фото нет.

На контрольных заданиях правильны 95 из 100 ответов при пороге IoU 0,5. Использовались 20 разных контрольных фото с повторениями. Этот показатель не является оценкой точности всего датасета.

75 ответов получены от исполнителей с минимум двумя ошибками на контролях. Для них установлен `review_flags: ["worker_failed_controls", ...]`.

Все ответы требуют независимой проверки: `review_status=pending`. Эти данные ещё не являются golden set. При формировании страниц проверки авторов рамок нужно исключить через ограничения выдачи API; наличия ID во входных данных недостаточно.
