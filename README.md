# Team 30 · Разметка бабочек

Эталонная разметка 400 фотографий iNaturalist с лицензией CC0 для сравнения моделей детекции. На каждом фото размечены видимые части всех взрослых бабочек, включая ночных. Сбор данных, первичная разметка и независимое ревью описаны в [паспорте датасета](review_dataset.md), [отчёте Bbox](results/bbox/README.md) и [настройках Review](yandex_tasks/review/setup/README.md).

## Датасет и материалы

- [Golden set](results/review/golden_set.jsonl) содержит 400 строк, 366 рамок и 106 кадров с пустым списком рамок. Координаты нормированы. Для загрузки фотографий используйте [манифест](data/manifests/main_400.jsonl) и [скрипт скачивания](scripts/download_dataset.py).
- [Происхождение итоговых ответов](results/review/golden_set_provenance.jsonl) и [журнал 11 исправлений](results/review/golden_set_corrections.jsonl) показывают, какие рамки использованы и какие альтернативы рассматривались.
- [Ответы по этапам](results/review/stage_answers.jsonl) содержат исходные ответы, голоса и контрольные задания. Идентификаторы исполнителей заменены стабильными псевдонимами.
- [Сводка](results/review/delivery_summary.json) и [настройки и расходы по пулам](results/review/pools_public.json) фиксируют результаты выгрузки. Расчёт по перечисленным пулам составляет 816,89 ₽ с комиссией 40%. Остаток на счёте при выгрузке составлял 19,11 ₽.

Golden set предназначен для оценки моделей на выборке команды. В [Яндекс Контест](https://contest.yandex.ru/contest/103082/) капитан отправляет предсказания выбранной модели на отдельном экзаменационном наборе.

## Шишов Иван

Я отвечал за второй этап разметки. Взял первичные ответы из пула Саши и настроил отдельный проект проверки в Яндекс Заданиях. Подготовил инструкцию с примерами, обучение, экзамен и рабочие контроли. Проверил интерфейс с несколькими фото на странице и клавишами 1–5. Исключил выдачу кадров авторам тех рамок, которые проверялись.

В основном ревью собрал по два независимых голоса на 399 фото. Оба ревьюера приняли 267 ответов. Остались 95 разногласий, 37 отклонений обоими и один кадр с ошибкой загрузки на первом этапе. Я настроил дополнительный набор разметчиков, проверил их экзаменационные рамки и выдал допуск четырём новым исполнителям. Организовал перерисовку 131 кадра и ещё один раунд независимого ревью. Два исходных ответа сохранил после ручного просмотра.

После повторного ревью я сам просмотрел и принял 56 кадров с разногласием. Для этих кадров дополнительно собрал третий голос: 51 разметку подтвердили, для пяти осталась отметка о расхождении. Для 20 кадров, отклонённых обоими, организовал новую разметку и проверку. На фото `588103612` сохранил предыдущую рамку, потому что она захватывает видимые усики.

Последние 11 спорных кадров разобрал с помощью модели. Затем организовал независимую разметку этих снимков людьми и проверку их новых рамок. В итоговый набор вошёл один принятый человеческий вариант. Для остальных десяти сохранились исправления с помощью модели, а альтернативные ответы и вердикты сохранены в журнале. Например, на `667238360` новый разметчик не поставил рамок, хотя на соседних снимках того же наблюдения видно две особи.

Собрал JSONL и сверил все 400 идентификаторов с исходным манифестом. Отдельно сохранил исходные ответы, вердикты, исправления и расходы, чтобы команда могла воспроизвести сборку.
